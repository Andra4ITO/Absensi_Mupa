Migrasi LocalStorage → Firebase Firestore

Sistem Presensi Digital MUPA — halaman manual, TERPISAH dari aplikasi (index / dashboard).
Cara kerja Migrasi hanya berjalan jika Anda menekan tombol MIGRATE TO FIRESTORE di halaman ini. Tidak ada migrasi otomatis saat login, buka dashboard, refresh, atau startup.
localStorage TIDAK pernah dihapus/diubah oleh halaman ini — tetap menjadi backup selamanya.
ID lama dipertahankan sebagai Document ID (mis. USR-001 → users/USR-001). Aman dijalankan berulang (dokumen identik dilewati — tanpa duplikasi).
Koneksi memakai yang sudah ada: window.FirebaseDB + window.FirestoreRepo (project dataabsen-aa6db) — tanpa inisialisasi baru, tanpa Firebase Auth, tanpa menyentuh Supabase, tanpa data/db.json.
Field terlarang (password, passwordHash, token, session, dsb.) tidak pernah dikirim ke Firestore.
